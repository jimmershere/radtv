1. What is R&Dtv?

R&Dtv (née B@Dtv, originally TerraKodi) is TheClawFirm's pre-configured Kodi distribution. It is packaging software—not a streaming service. R&Dtv does not host, transmit, or mirror audiovisual content.

  • Installs and configures Kodi with a curated addon stack
  • Merges lawful free/ad-supported IPTV into a single playlist
  • Applies a Black Donnellys color theme
  • Optionally wires a home NAS (floor2) and self-hosted *arr + Jellyfin stack
  • Automates Real-Debrid, TorBox, Trakt, and VPN via ./radtv setup

2. What is floor2?

floor2 is TheClawFirm's reference media server: an 8 TB ZFS box on the LAN at 192.168.1.206.

Three roles

  1. Storage backbone — ZFS /datapool/media
  2. Automation hub — Docker *arr stack + Jellyfin
  3. Network share — NFS/SMB exports for direct Kodi access

5. How media flows

5.1 Acquisition

  1. Prowlarr aggregates indexers; Byparr bypasses Cloudflare
  2. Sonarr/Radarr send grabs to download clients
  3. rdt-client (RD), qBittorrent (VPN), SABnzbd (Usenet) fetch files
  4. Completed media lands in /datapool/media/movies and /datapool/media/tv

5.2 Playback

  • Jellyfin indexes /media read-only → browsers, apps, Kodi sync
  • NFS/SMB → Kodi direct library scan
  • IPTV/scrapers → streaming without owned files

7. Jellyfin: the owned-library frontend

Jellyfin is the presentation layer for *arr-managed media. Sonarr/Radarr/download clients write; Jellyfin reads and serves.

LibraryContainer path
Movies/media/movies
Shows/media/tv

Mount: /datapool/media:/media:ro (read-only by design).

Bootstrap provisioning

When opted in, step_jellyfin:

  1. Starts Jellyfin container on floor2
  2. Creates admin, libraries, API key via REST API
  3. Installs Jellyfin-for-Kodi and pre-seeds connection
./radtv repair jellyfin

10. First-time setup tutorial

Path A — full automated (recommended)

git clone https://github.com/jimmershere/radtv.git
cd radtv
cp config/radtv.conf.example config/radtv.conf
./radtv setup

Then: Programs → R&Dtv Wizard, TV → Guide, Jellyfin at :8096.

Path B — NAS only

sudo bash media-server/setup-nfs.sh   # on floor2
bash install.sh                        # on client

Path C — Jellyfin on existing stack

./radtv repair jellyfin

Path D — Windows

pwsh ./install.ps1

13. Security & credentials

Never commit credentials. The handover file lives only on floor2: /datapool/preserved/badtv-arr/jellyfin/rdtv-admin.json (mode 0600). Retrieve over trusted SSH or a password manager.
  • Prefer a non-admin Jellyfin user for daily playback
  • Rotate password + API key if the handover file is exposed
  • qBittorrent traffic routes through Gluetun VPN once .env is filled
